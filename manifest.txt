# line and writes the ROOT index.html - the page Pages serves.

# THE ORDER IS THE MANIFEST'S JOB, not the filenames'. The
# files were once numbered 00..15, from the era when this was
# a userscript organised into scrolled-past sections; the
# numbers said nothing the line below them did not, and a
# project meant to last should not carry a previous era's
# filing system forever. Names say what a file is FOR, and
# this list says what order it loads in.
#
# Only one ordering fact is load-bearing: header.js opens the
# closure and closure-footer.js closes it, so they are first
# and last. Everything between them is function declarations,
# which hoist across the whole concatenated script.
